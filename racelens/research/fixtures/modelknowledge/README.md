# modelknowledge fixtures

Machine-readable priors distilled from `research/modelknowledge.md`. Every file is **constructed** (no live fetch was possible from this container); each carries a `_fixtureNote`, and every numeric claim carries `confidence` (high/medium/low) and a `source` URL that is listed in the report. Keys in `factor-weights.json` match `BASE_WEIGHTS` in `src/server/core/factors.ts`. The worked example uses Flemington, 2026-10-24.
