Decoding helpers the adapter needs:

* **Punters legacy `{"r": ...}` wrapper**: `JSON.parse(Buffer.from(rot13(r), 'base64'))` — verify against the REAL encoded file (decodes to the REAL decoded file byte-for-byte in content).
* **Racenet `window.__NUXT__`**: extract `window.__NUXT__=` … `;</script>` and evaluate in `node:vm` (`vm.runInNewContext(src, {}, {timeout: 5000})`); it is a self-invoking function with positional args, not JSON. Then `apollo.defaultClient` is an Apollo-Client-2 normalized cache: keys `Type:id`, generated keys `$Type:id.field`, refs `{type:"id", generated, id, typename}`.
